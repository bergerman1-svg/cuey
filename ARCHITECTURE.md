# Cuey — Architecture & Status

_Last updated: 2026-10-22 · app v0.17.5_

Cuey is a free, simple playback app for live events run by non-technical people
(teachers, lecturers, producers): drop videos/slides into a cue list, press **GO**,
the second screen shows it. This document is the single map of what exists,
how it is built, and where it is going.

---

## 1. Product principles (from Avi)

| Rule | Meaning in practice |
|---|---|
| **Never break what exists** | `app/cuey.html` is the one source of truth; every change must keep the current show-running flow working. |
| **Free to start (no "free forever" promise in copy)** | Free shows a small "Powered by Cuey" badge in the screen corner; the one-time Cuey Studio purchase removes it. Site/app copy says "Try it free" — Avi does not want to commit publicly to "free forever" (2026-10-23). |
| **Never lock a feature that endangers a live event** | GO, BLACK, output window, open/save — always available. Badge, never a block: no "sign in to continue", ever; offline = everything works as last seen. |
| **Look like Canva / CapCut** | Dark UI, lime `#C8FF00` for GO/live, orange `#FF751F` for NEXT/standby/auto, Poppins + Heebo + JetBrains Mono. |
| **Keep it simple** | No templates, no "my shows" library in mobile; one list, one button. |
| **Language** | Product UI & website in English (Hebrew toggle inside the app); conversation with Avi in Hebrew. |
| **Branding** | Avi's designed logo — orange-triangle wordmark is primary, white triangle is the mono variant. |

## 4. Inside `app/cuey.html`

### 4.1 Data model
```js
cue = { id, file, type:'video'|'image'|'audio', name, url, thumb,
        loop, trans:'cut'|'dissolve', dur,          // dur = dissolve seconds
        onEnd:'hold'|'next'|'black',                 // what happens when media ends
        scale:'fit'|'fill'|'stretch', vol, avol,     // video volume, attached-audio volume
        audio,                                       // optional audio file attached to a still
        standby, hold, in, out,                      // standby-first-frame, hold seconds, trim points
        text,                                        // text slide payload (rendered to PNG)
        bad, handle }                                // missing file flag, FileSystem handle
show file (.cuey) = JSON of the cue list + settings (files referenced by name/handle)
```

### 4.2 Stage engine
`makeStage(doc, root, mutedFn)` — two stacked layers (`<video>` / `<img>`) with Web Animations API
crossfades (`fade(el,to,ms)`), so a dissolve interrupted mid-way never dips to black.
Two instances: **PROGRAM preview** (in the operator window, muted) and the **Output window**
(`window.open('cuey_output')`, fullscreen on the second display in Electron).
`BLACK` is a layer on top; `FREEZE` pauses both.

### 4.3 Main flows
| Area | Functions |
|---|---|
| Cue list | `addFiles`, `render`, `makeThumb`, drag reorder, duplicate, delete |
| Playback | `show(i,force)`, `advance/go/back`, `armHold` (hold / auto-next timers), `setBlack`, `playPause`, `toggleFreeze`, `keyHandler` (Space/Enter = GO, B = black, F = freeze, ←/→) |
| Timeline | `tlUpdate/tlSource`, `seekTo(t,scrub)` (free scrub also drives output), `setIn/setOut`, `markerDrag` (IN/OUT triangles), ±10 s, 5-second end countdown |
| Audio | `pickAudio/setAudio/startSlideAudio/stopSlideAudio` — audio on stills; **audio-only cue** shows `BLACK_PNG` on screen while playing |
| Text slides | `renderTextSlide/applyText/editText` — canvas → PNG, editable names/titles |
| Files | File System Access API + IndexedDB handles: `saveShow/saveShowAs/openShow/loadShowFromText`; native menu in Electron |
| Export | `startExport/drawFrame/finishExport/saveExport` — 1920×1080 canvas composite + AudioContext → MediaRecorder (avc1 preferred) → MP4/WebM |
| i18n | `L.en / L.he`, `t(key)`, `applyLang()`, `dir` + logical CSS; `localStorage cuey.lang` |
| Output | `openOut`, `setStatus`, `clearStages` |
| Share screen (v0.17) | `startShare/stopShare/shConnect/shOffer` — PROGRAM composited to a 1920×1080 canvas (`drawFrame`) + audio from `acDest`, streamed over **WebRTC** to `docs/s/?c=CODE`; signalling (hello/offer/answer) via ntfy.sh topic `cuey-v1-CODE`; STUN only, so same-LAN is the reliable case |
| Badge | `BADGE` (base64 PNG), `licensed` flag (localStorage `cuey.licensed`, to be set by the account check), drawn in `drawFrame` (share + export) and as `#badge` in the Output window |

### 4.4 Notable fixes baked in (don't regress)
- Dissolve uses Web Animations with full duration (CSS transition reversal dipped dark).
- Auto-next re-arms its timer inside the onEnd handler (previously never fired on live slides).
- Volume slider vs. HTML5 drag: cards are draggable only from number/thumb/name.
- Scrubbing back then Play works (seek no longer leaves the element in a stuck state).
- Service worker registers only over http(s) and never inside Electron.

## 5. Mobile prototype (`docs/mobile/`)

Purpose: validate the **phone-as-remote** flow before building it for real. Two screens, nothing else.

```
 Screen 1 · Build            Screen 2 · Remote
 ─────────────────           ──────────────────────────────
 + Add from gallery  ──►     [📺 Show on screen]  ← pulsing CTA, opens link sheet
 cue cards (thumb,            NOW / NEXT previews
   cut/dissolve, loop,        GO (big) · back · BLACK
   wait/continue)             position 3 / 12
 reorder: long-press          Link sheet: QR · code CUEY-4K7P
   anywhere, or ⇅ handle        [⎘ Copy link] [⤴ Share link] → OS share sheet
 [Go live] → "download        (first Go live opens the sheet automatically)
   to phone" overlay
```

Decisions taken from testing on Avi's Android phone:
- Reorder = **long-press anywhere on the card** (380 ms, haptic) → ghost follows finger, dashed
  placeholder moves, auto-scroll near edges. Handle (`⇅`) sits on the start side (right in RTL).
  Tap = settings sheet, swipe = scroll.
- Real files from the gallery (`<input type=file multiple accept="video/*,image/*">`), canvas thumbnails.
- Share = two buttons only: Copy link, Share link (native share → WhatsApp/mail/anything). No per-app tabs.
- Hidden states need `[hidden]{display:none!important}`; bottom bar is `pointer-events:none` except buttons.

What is **fake** in the mockup: QR, code, link `cuey.app/s/4k7p`, "1 screen connected", the download step.

| | Free | Cuey Studio | Pro |
|---|---|---|---|
| Price | 0, forever | **$8 one-time** per account (chosen over monthly) | Subscription (price set once there is something to sell) |
| Running a show | Everything — no cue-count limits (cues, GO, dissolve, audio, text, IN/OUT, basic share screen) | Same | Same |
| Screen badge | "Powered by Cuey" in the corner (Output, shared screen) | None | None, or the venue's logo |
| Studio tools | — | **Export MP4** + **Slide show** (replaced AUTO in v0.20.0 — groups of cues that run and loop by themselves; free to build and preview, Studio to run on the output) (free during beta, marked STUDIO in the app — v0.17.2) | Included |
| Account | Not needed | Yes (Google / email) — purchase follows the account to every computer | Yes |
| Phone remote + screen link | 1 screen, 1 active show, ~500 MB, deleted 24 h after | Same | Multiple screens, no limits |
| Cloud & team | — | — | Shows in the cloud, share with a colleague, several operators |
| Design in Canva | — | — | Pro: "Design in Canva" / "Edit in Canva" from inside Cuey (Connect API + Return navigation; pages come back as cues) |

Rules: badge, never a block; offline always works; sign-in is offered after the first GO, not before; Pro only sells what needs a server. Payments on the web (Lemon Squeezy / Paddle as merchant of record), apps only sign in — avoids the 15–30% app-store cut.

Licensing mechanics (to build): Supabase accounts → after purchase the webhook marks the account → app fetches a **signed entitlement** once online and caches it (valid offline indefinitely) → `licensed=true` hides the badge and unlocks Studio tools. If the check fails for any reason the app keeps working with the badge.

## 10. Accounts (v0.18.0)

Supabase project **Cuey** (`lgemvnntlgasxhrpsdww`, eu-central-1, free plan). The app talks to it with plain `fetch` (no SDK, so the single file stays dependency-free).

- **Sign-in = 6-digit code by email** (not a magic link) — works the same in Electron, the PWA and a local file; no redirect URLs. Requires the *Magic Link* email template to contain `{{ .Token }}` (set in the dashboard).
- Session (access + refresh token) in `localStorage cuey.sess`; refreshed on demand.
- `public.entitlements(user_id, product 'studio'|'pro', source, order_ref, expires_at)` — RLS: a user can **read only their own rows**; clients cannot write. Rows are written by the payment webhook (stage 1c, service role) or by hand.
- On start and when the network returns, the app reads entitlements → sets `licensed` (cached in `cuey.licensed`, so it holds offline). Offline / any error = keep last known state; never blocks a show.
- Soft nudge: a small banner bottom-left, 4 s after the first GO of a session, only if signed out; ✕ = quiet for 3 days; never shown again after a sign-in. Events: `signin-shown`, `signin-click`, `signin-dismiss`, `signin-open-*`, `signin-code-sent`, `signin-done(-ever)`.
- Grant Studio by hand (e.g. to a pilot): `insert into public.entitlements(user_id,product,source) select id,'studio','gift' from auth.users where email='…';`

## 16. Free backgrounds & free music (Pixabay) — v0.27.0
- **Free backgrounds** (Add → "Free backgrounds", and "🌄 Free backgrounds…" in the text-slide dialog): search Pixabay photos and moving loops (videos). Hebrew chips map to English queries (`PB_CHIPS`, `PB_HE`), free text in Hebrew is mapped word by word.
- Proxy: Supabase Edge Function `pixabay` (verify_jwt off; read-only). `?q=&type=image|video&page=` → Pixabay API with secret `PIXABAY_KEY` (set by Avi in Function secrets; the key is never in the app). Results cached 24 h in `public.pixabay_cache` (RLS on, no policies → service role only), as the Pixabay API terms require. `?dl=<url>` streams a chosen file (only pixabay.com / cdn.pixabay.com) with CORS, used when a direct download is blocked.
- A picked file is stored in IndexedDB as `gen:pixabay-<id>.jpg|mp4` (same path as PDF pages) → the show works offline and reopens. Picked loops are added as looping video cues named "<search> · Pixabay". In text-slide mode only photos are offered (no text over video yet).
- Credit line "Free photos and videos from Pixabay" is always shown in the search dialog (API rule).
- **Free music**: no Pixabay music API exists and their terms forbid bundling/redistributing tracks, so the tile opens pixabay.com/music in a new tab with 3 steps (listen → Download → drag the file into the cue list). Desktop (later): catch the download in an in-app window and add it automatically.

## 17. Create cue — v0.28.0 (replaces the old text-slide dialog)
- Add → **Create cue** (`#mkDlg`, `openCard(it|null)`): 1) background = colour / from computer / free library (Pixabay photo or moving loop), with Darken; 2) text = title + lines, colour, size, optional box, presets Top / Center / Lower third, and **drag the text anywhere** on the live 16:9 preview (snaps to the centre lines); 3) music (optional) = from computer or Free music. Right-click → "Edit in Create cue…" reopens it.
- Data: `it.text={title,body,color,size,x,y,box,bg,bgKind:'color'|'image'|'video',bgName,bgImg,bgFile,dim}`. Old text slides (no bgKind/x/y) open centred, unchanged.
- Colour / picture background → `type:'image'`, one 1920×1080 PNG (`renderTextSlide`). Moving background → `type:'video'` (the loop file, `loop:true`, `scale:'fill'`) + `it.overlay` = transparent 1920×1080 PNG (dim + text, `renderOverlay`). `makeStage.show` adds `<img class="ov">` above the video in preview and Output; `drawFrame` draws every child of a layer, so Share screen and Export MP4 include the text; thumbnails get the overlay too.
- Save/open: `text.bgKind/x/y/box` are stored; a moving-background cue stores the video as its file (`c.file===text.bgName`), found again via file handles or `gen:` (library files and computer pictures are kept in IndexedDB).
- One layout function (`drawCardLayer`) draws the preview, the PNG and the overlay, so what you see while dragging is what goes on the screen.
