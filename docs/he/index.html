מתחילים בחינם

לינק אחד. כל מסך.

לוחצים שתף מסך בגרסת הדפדפן, ו-Cuey נותן לינק. פותחים אותו בכל מכשיר עם אינטרנט — אייפד, טלפון, דפדפן של טלוויזיה חכמה או מחשב אחר — והוא מציג בדיוק את מה שמוצג ב-PROGRAM, בזמן אמת ועם סאונד.

  • בלי כבלים למסכי האירוע — המסך יכול להיות בצד השני של האולם או בעיר אחרת
  • כמה מסכים יכולים לפתוח את אותו לינק בבת אחת
  • ואתם ממשיכים להריץ את האירוע מהמחשב שלכם
